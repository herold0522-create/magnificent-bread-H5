# 豪士藜麦无边吐司 · 像素烘焙工坊 H5

一个竖屏 H5 休闲制作小游戏（类「老爹早餐店」制作台玩法），围绕**豪士藜麦无边吐司**的「营养 · 松软 · 没有边 · 好吃到没边了」打造。

## 玩法

发酵加载页 → 首页 → 六个制作台连续操作 → 出炉评分：

1. **选材台** — 从传送带拖好料进面盆（红藜麦/高筋粉/酵母/水…），避开坏料。
2. **揉面台** — 跟着节奏条在绿区揉，松软上升；偏了则面团变硬、难嚼上升。
3. **发酵箱** — 控温，在最佳发酵区取出。
4. **烘焙炉** — 控火力，金黄最佳区出炉（太早没熟、太晚焦硬）。
5. **切片机** — 切割线到标准厚度时下刀。
6. **去边台** — 沿虚线切掉四条吐司边，打跑「硬边小怪兽」，组成「好吃到没边了」。

最终根据 **营养 / 美味 / 松软 / 咀嚼难度 / 无边完成度** 生成 **S / A / B / C** 评价。

## 本地运行

纯静态，无需构建。任意静态服务器即可：

```bash
python -m http.server 5174
# 打开 http://localhost:5174
```
